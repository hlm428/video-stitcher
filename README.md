# 视频拼接小工具

把几个视频片段拼成一个完整视频。纯前端（ffmpeg.wasm），打开网页就能用。

- 上传 → 排序（拖动）→ 剪头去尾 → 导出（720p + 480p）
- 片段间淡入淡出（默认 0.125s）、旁白 + BGM（自动低 15dB）、响度统一 -16 LUFS
- 「柑橘预设」一键填好 6 段 × 10s 的参数（接缝 9.875 / 19.75 / 29.625 / 39.5 / 49.375 秒）
- 浏览器导出跑不动时，一键生成完整 ffmpeg 命令（含字幕烧录）本地跑
- 项目自动保存本地（元数据 + 文件），重开页面继续改
- SRT 字幕烧录只在命令版支持（浏览器内 wasm 核心不含 libass）
